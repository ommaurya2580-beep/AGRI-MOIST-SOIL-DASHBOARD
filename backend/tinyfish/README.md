# TinyFish Agricultural Web Intelligence Module (AgriPulse)

This module integrates the **TinyFish Search & Fetch API** into AgriPulse as an independent, optional, and fully removable advisory layer.

---

## 1. Core Principles

- **Zero Core Dependency**: If this module is disabled, if the API key is missing, or if the external API times out, AgriPulse's core IoT sensors, irrigation controls, and CNN/YOLO models continue operating normally.
- **Strict Separation of Diagnosis vs. Web Evidence**: Web search results do **NOT** overwrite or alter the raw diagnostic output or confidence scores generated by EfficientNet-B0 (Disease) or YOLO11s (Pest).
- **SSRF & Security Protected**: User inputs are strictly sanitized; arbitrary URL fetching is blocked.

---

## 2. Environment Configuration

Add the following to your `backend/.env` file:

```env
# TinyFish Integration (Optional)
TINYFISH_ENABLED=true
TINYFISH_API_KEY=your_actual_tinyfish_api_key_here
TINYFISH_SEARCH_URL=https://api.search.tinyfish.ai
TINYFISH_FETCH_URL=https://api.fetch.tinyfish.ai
TINYFISH_TIMEOUT_MS=20000
```

> **Note**: To disable the module, simply set `TINYFISH_ENABLED=false` or leave `TINYFISH_API_KEY` blank.

## 3. Endpoints

### `GET /api/tinyfish/status`
Checks if the TinyFish module is enabled and has credentials configured.

**Response:**
```json
{
  "enabled": true,
  "message": "TinyFish Agricultural Web Intelligence is active and configured."
}
```

### `POST /api/tinyfish/advisories`
Searches verified extension literature (ICAR, KVK, Ministry of Agriculture) and validates recommendations.

**Request Body:**
```json
{
  "crop": "Wheat",
  "issue": "Yellow Rust",
  "chemical": "Tilt 25 EC (Propiconazole)",
  "location": "Punjab",
  "stage": "Tillering"
}
```

**Response:**
```json
{
  "success": true,
  "enabled": true,
  "crop": "Wheat",
  "issue": "Yellow Rust",
  "chemical": "Tilt 25 EC (Propiconazole)",
```

## 4. How to Completely Remove This Module (Zero-Trace)

If you ever wish to remove TinyFish completely from AgriPulse:
1. Delete the `backend/tinyfish/` folder.
2. In `backend/server.js`, remove the 4 lines mounting `tinyfishRoutes`:
   ```javascript
   const tinyfishRoutes = require('./tinyfish/tinyfishRoutes');
   app.use('/api/tinyfish', tinyfishRoutes);
   ```
3. In `frontend/src/pages/FertilizerGuide.jsx` (and/or `UnifiedAnalysisFlow.jsx`), remove the `<AgriculturalWebAdvisories />` component.
4. Done! The core AgriPulse application remains 100% untouched.
